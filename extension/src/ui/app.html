Deep listing intelligence (phase 2)
Etsy API key — for the real 13 tags

Etsy never renders a listing's 13 tags in the page, so scraping can only recover a close proxy. With a free key from etsy.com/developers the deep scrape also calls the Open API and stores the exact tags, plus an authoritative description, favourites, views and stock. Stored locally, sent only to api.etsy.com, never written to the log. tagSource records which path produced each row.

Each listing is one extra page request, so this phase is the slow one. Velocity fields stay null until the same listing has been seen twice, at least 6 hours apart.
